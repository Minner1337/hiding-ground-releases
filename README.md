# Hiding Ground

Downloads for Hiding Ground: chat, voice, screen and file sharing with your friends, on servers you host on your own PCs.

## Download

Open the [latest release](https://github.com/Minner1337/hiding-ground-releases/releases/latest) and download **one** file:

- **HidingGround.exe** (about 2 MB). Needs the free [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) installed once.
- **HidingGround-Standalone.exe** (about 64 MB). Needs nothing installed.

Both need the Microsoft Edge WebView2 Runtime, which Windows 10 and 11 already have.

Keep the exe in a folder you can write to, such as Documents or Downloads (not Program Files). It keeps itself up to date:
new versions download in the background and install when you restart it.

The other two files, `release.json` and `release.json.sig`, are for the app's updater: they let it check that an update
really comes from the author and arrived intact.
